# Greek terminology glossary — Phase 4 register lock

**Status:** locked at end of Phase 4.B (Long COVID).
**Scope:** canonical EN→EL terminology for clinical content; binding for all subsequent Phase 4 clusters (4.C Fibromyalgia, 4.D Dermatology, 4.E Plastic Surgery, 4.F Women's Health) and any later editorial work.
**Authority:** the entries below are derived from approved Long COVID translations (`condition.long-covid` and `departments.neurology.applications[Long COVID]`) plus the inherited neurology register from Phase 2.B. Where the inherited register and the Phase 4.B translation diverge, this glossary records the Phase 4.B form as the going-forward standard.

Update this file when a new cluster introduces a term not yet listed; do not silently invent new translations on the page.

## 3. Caveat and uncertainty register (binding for emerging-tier content)

The register chosen for Long COVID's single-research-group caveat is the canonical phrasing for any future emerging-evidence indication where independent replication is pending. **Do not soften in EL.**

| EN | EL |
|---|---|
| The evidence base is currently anchored to a single research group; independent replication is awaited. | Η τεκμηρίωση βασίζεται προς το παρόν σε μία ερευνητική ομάδα — ανεξάρτητη επιβεβαίωση εκκρεμεί. |
| may improve | μπορεί να βελτιώσει |
| associated with | συσχετίζεται με |
| preliminary evidence suggests | πρώιμα στοιχεία υποδηλώνουν |
| significant improvement (statistical) | σημαντική βελτίωση |
| sustained at follow-up | διατηρούνται σε παρακολούθηση |
| benefits sustained | τα οφέλη διατηρούνται |

**Forbidden register** (carried over from Phase 4 plan anti-marketing reminder; never to appear in EL or EN):
- "transformative" / "μεταμορφωτικό"
- "breakthrough" / "ανακάλυψη"
- "revolutionary" / "επαναστατικό"
- "the answer to X" / "η λύση για"
- "miracle" / "θαύμα"

## 6. Trial and authority names — keep in original

The following are kept untranslated (proper nouns / acronyms with international currency):

- HOT-LoCO (Karolinska trial)
- UHMS (Undersea and Hyperbaric Medical Society)
- Medicare / Medicaid
- FDA
- Cochrane
- Author surnames in citations: Zilberman-Itskovich, Hadanny, Katz, Kjellberg, Figueroa, Wright, Efrati, etc.

DOI URLs and journal names are kept in Latin (e.g. "Sci Reports", "BMJ Open", "Frontiers in Medicine").
